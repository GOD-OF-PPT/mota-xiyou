# 大圣：舍利魔塔

十八层固定地图的西游策略冒险。每层21×21，默认用可探索地图覆盖整个视口；M进入整层规划，R回到悟空的探索视野。十六枚外舍利须逐一寻回，五印解锁神通，最终觉醒自身第十七颗无骨舍利。纯HTML/CSS/JavaScript，直接打开index.html即可游玩，无构建、无后端，所有美术资源随项目本地提供。

## 游玩

直接打开 `index.html`，或在目录运行 `python -m http.server 8765` 后访问 `http://127.0.0.1:8765/`。

- 方向键/WASD移动；点击地面寻路，点敌人、机关或宝物先看信息。
- 1–5切换行走、火眼、金箍架桥、青蝉化形、毫毛分身；F主动交互，经过楼梯与扳杆不会自动触发。碰到敌人先展开战损提示；松开后再次按同一方向即可迎战，也可点迎战或按 F。长按方向不会自动确认战斗。
- M全图规划；R归位悟空；「此层经卷」显示本层问题、机会成本与目标定位。
- C展开/收起人物详情；I行囊与法器；J因果簿和乘云回访；B敌情；H规则与声音/动态设置。
- Space补全或推进短句；移动或 Esc 收起，全文可在因果手记查看。右上画境切换『玄金古寺／青绿壁画』。
- Ctrl+S独立手动存档；L选择读档；Z回溯；Y/Ctrl+Y重做；Esc关闭面板。自动进度不覆盖手动档，力竭保留战前状态。

首次按所选画境载入本地运行PNG并显示真实进度。完整资源均在本地，离线可用；另一套风格按需加载。切换只换表现层，不改属性、资源、机关、路线或存档；失败保留当前风格。个别启动图片载入失败时明确提示并允许基础图形继续。

## 透明规则

战损与实战共用 `TowerRules.battle`：攻击须破防，出棒数向上取整，普通敌人由行者先手；先攻、法术、余毒、反震与首领三相均明确展示。生命须严格大于总损失才获胜。守卫、钥匙、成长和道具不刷新。

六件法器最多同时装配两件，须站莲灯免费切换。攻击、防御、首棒、先攻、法术、反震、战利功德与神通代价的利弊全部进入真实预览。莲灯补灵息，不免费回生命。凝息珠可补息、换钱/生命，或留给最终三套准备。

v1–v4旧档保留。旧版大地图和本轮修订首次载入会安全回到本层莲灯，保留原属性、资源、选择及机关；当前修订存档保持原坐标。已领取的旧供给不会再通过新选择重复领奖。

剧情为受《西游记后传》启发的原创平行篇章；无相塔、五印和守塔分歧为本作设定。舍利数为16外在+悟空自身，十八层不等于十八颗舍利。
