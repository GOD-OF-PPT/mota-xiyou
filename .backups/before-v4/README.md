# 大圣：舍利魔塔

西游像素策略冒险。十八层固定地图、六个篇章、五重心印、十六枚外舍利与悟空自身第十七颗无骨舍利、两种结局。纯 HTML / CSS / JavaScript，无依赖、无构建、无后端、无外部素材请求。

当前版本强化了路线契约、分身调度、首领三相与小屏交互。第五层三条路线分别付出青钥匙、黄钥匙或更多战斗，北匣只兑现一份所选奖励。第十一层三个镜台最多同时驻守两处，攻击经卷和防御经卷只取一份，取卷后需召回并重新部署才能上行。最终首领连续结算三相，三套准备的生命、凝息珠代价都可在确认前比较。

v3 将《西游记后传》的双塔、弱水救援、炼炉、善念和无骨舍利主题改编为原创平行篇章。无相塔、点灯僧、五重心印与守塔分歧为本作原创。舍利按 3＋3＋3＋3＋4 分组，成长仍只有原有五次奖励；第十七颗由悟空战后觉醒，不是另一个可拾取宝箱。

六章分别考查免费辨真开路、跨层双塔共鸣、救援与可逆水位、跨层三炉联动、公开代价的救人与成长、最终三相准备。八戒稳定水脉后，水轮在低水西渡与高水东渡间切换；两路各有独占资源，南部莲灯和下楼归路始终安全。七伤护送花70生命救出三名映身并开放真实侧路；也可花20功德取防御，或保留资源走原路。

表现层加入悟空四向行走、四段棒势、受击、三种首领剪影、六章建筑和局部光照。双塔檐线与炉窗读取真实机关，心印复明在回访与读档后保留。架棒、化蝉、毫毛与召回各有过程，化蝉只飞去卸闩再返回，不改变真身位置。六章本地合成音乐与音效可独立设置；标准、简洁、减弱动态尊重系统偏好，震动默认关闭。新动作收束旧效果，跳过演出不改变结算。

## 游玩

用现代浏览器直接打开 `index.html`。也可在此目录运行 `python -m http.server 8765` 后访问 `http://localhost:8765`。服务器仅为可选的静态文件预览。

- 方向键 / WASD：移动；点击地面：自动寻路；点守卫或机关先查看，再主动接近与确认。
- 1–5：行走、火眼金睛、金箍架桥、青蝉化形、毫毛分身。
- I：背包；J：因果簿与乘云回访；B：本层敌情；H：完整规则。
- E：与选中的相邻目标、脚下或面前目标交互。经过扳杆、楼梯不会自动触发。
- Ctrl+S：写入独立手动存档；L：选择手动或自动进度；Z：回溯；Y / Ctrl+Y：重做。连续普通移动合为一组，保留当前会话最近 30 组行动；Esc：关闭界面或返回行走。
- 手机支持点选地图与方向按钮。声音默认关闭，可在顶部开启原创合成配乐与音效。

每一步自动存档；力竭保留战前进度。自动保存不会覆盖手动存档，新冒险也保留独立手动档。背包可导出、导入 JSON。v1/v2存档自动迁移并保留资源，已越过章节补齐新增救援条件；已领百锁灵晶、千丝朱砂或问心碧髓的档沿用对应成长份额，不重复发放；只开旧门、尚未领取成长的奖励仍可取得。回溯记录属于当前会话，读档后重新建立。

## 策略规则

攻击必须高于敌防御。每棒伤害为攻击减敌防御，出棒次数为敌生命除以每棒伤害、向上取整。普通敌人还击次数为出棒次数减一；每次还击伤害为敌攻击减行者防御、最低为零。敌人先手、法术、余毒、反震和首领心火均明确列在敌情中，预览与结算共用同一个纯计算函数。生命必须严格高于总损失，才可获胜。

第 3／6／9 层分别觉醒架桥、穿栅与分身，第 12 层获得法术减伤，第 15 层集齐五印及十六外舍利。主动神通共用六点灵息；走上莲灯免费补息，主动交互打开供奉。架桥与穿栅永久改变地形，深弱水只能通过水轮改变渡路；分身可在同层免费召回，第十一层有双驻守上限。若召回会切断退路，须先离开藏室或取得经卷。第九层后可耗一灵息乘云回访，因果簿记录每重心印对应的旧区变化并提供定位。

黄、青钥匙各三把，分别与同色门、第五层契约竞争。门与资源均不刷新，部分路线需绕行或等待能力觉醒。生命无上限，成长、治疗和金钱有限。供奉同类价格逐次提高，各层共用价格表。凝息珠除补满灵息，也可在灯前换 8 金或 50 生命，或保留给首领准备：执棒破阵无珠，定海镇心耗一珠，毫毛合击耗两珠。三相有独立的护甲、行动顺序与法术规则，整场预览与实战共用同一计算函数。

## 代码

- `js/world.js`：十八层手工地图、资源配给、敌人、舍利与剧情。
- `js/engine.js`：唯一状态源、战斗纯函数、碰撞、机关、成长、回溯和持久化。
- `js/renderer.js`：原创代码像素美术、六章建筑、角色姿态、神通过程与持久状态光照。
- `js/ui.js`：输入、敌情、菜单、剧情、结局与响应交互。
- `js/audio.js`：六章 Web Audio 合成配乐、神通与材质音效。
- `css/style.css`：桌面与移动布局、主题与无障碍焦点样式。

## 已完成的验证

`tests/engine-check.cjs` 覆盖独立战损计算、实际战斗结算、敌人特性、资源消耗、存档与回溯、十八层楼梯门槛、关键机关的必经性。

`tests/upgrade-rules-check.cjs` 验证显式交互、成组回溯与重做、独立存档、旧档迁移、契约互斥、双分身与安全召回、三相计算、凝息珠供奉、攻击临界值及回访。

`tests/v3-rules-check.cjs` 覆盖辨真、跨层双塔、救援门槛、弱水与存读位置、三炉条件、16＋1计数、旧档预算和设置隔离。

`tests/adventure-check.cjs` 只调用正式游戏行动，不写入位置、属性或机关状态；支持 `TOWER_BUILD=none/atk/def/mixed`、`TOWER_ROUTE=blue/gold/free`、`TOWER_SILK=atk/def`、`BOSS_PLAN=direct/anchor/echoes`、`SEVEN_ROUTE=rescue/power`、`REVISIT_ALL=true` 和 `USE_RESCUE_BYPASS=true`。当前完整记录为 `tests/playthrough-v3-*.json`，四套覆盖不同实体路线、经卷、七伤结果和首领准备；混合路线完成五处回访并保留藏经守卫。无属性供奉方案仍会按需要购买有限治疗。

`tests/v3-browser-playthrough.cjs` 通过正式行动回放与真实鼠标操作验证免费辨真、双塔、八戒救援、水轮、契约、独占经卷、分身回收、七伤护送、三相准备、16＋1觉醒、跳过、双结局及手动存档。旧browser-playthrough入口转向当前脚本。`tests/presentation-v3-check.cjs` 检查桌面与手机横竖屏、16环菜单、独立声音重载和系统减弱动态。`tests/upgrade-ui-check.cjs` 保留敌情、点击自身、独立存档和重做检查。

`research/progress-v3.json` 记录每阶段“改前问题—具体提升—证据—反思—修正”。`audits/v3-renderer-reflection.json` 附角色、六章对比与减弱动态证据。自动回放能验证规则和完整流程；首次游玩理解度、声音主观品质与长期乐趣尚未经真人用户研究。研究出处在 `research/presentation-and-sequel-brief.json`；`audits/` 内其他早期审计与v2记录属于历史资料。

验证脚本需要 Node.js 与本机 Playwright；游玩无需安装它们。
