# 大圣：舍利魔塔

十八层固定地图的西游策略冒险。每层21×21，默认用可探索地图覆盖整个视口；M进入整层规划，F回到悟空的探索视野。十六枚外舍利须逐一寻回，五印解锁神通，最终觉醒自身第十七颗无骨舍利。纯HTML/CSS/JavaScript，直接打开index.html即可游玩，无构建、无后端，所有美术资源随项目本地提供。

## 游玩

直接打开 `index.html`，或在目录运行 `python -m http.server 8765` 后访问 `http://127.0.0.1:8765/`。

- 方向键/WASD移动；点击地面寻路，点敌人、机关或宝物先看信息。
- 1–5切换行走、火眼、金箍架桥、青蝉化形、毫毛分身；E主动交互，经过楼梯与扳杆不会自动触发。碰到敌人先展开战损提示；松开后再次按同一方向即可迎战，也可点迎战或按 E。长按方向不会自动确认战斗。
- M全图规划；F归位悟空；「此层经卷」显示本层问题、机会成本与目标定位。
- C展开/收起人物详情；I行囊与法器；J因果簿和乘云回访；B敌情；H规则与声音/动态设置。
- Space推进对白；移动会收起对白但保留阅读位置，点回响可续读。右上画境切换『玄金古寺／青绿壁画』。
- Ctrl+S独立手动存档；L选择读档；Z回溯；Y/Ctrl+Y重做；Esc关闭面板。自动进度不覆盖手动档，力竭保留战前状态。

首次按所选画境载入9张运行PNG并显示真实进度。完整资源均在本地，离线可用；另一套风格按需加载。切换只换表现层，不改属性、资源、机关、路线或存档；失败保留当前风格。个别启动图片载入失败时明确提示并允许基础图形继续。

## v9 PC 问题修复

本轮按试玩反馈修复关卡用途、剧情与场景交互；优先 PC，未开展手机兼容工作。逐项原因、实施及验收见 `docs/v9-repair-report.md`。

- 遇怪先预览，松开后再按同方向攻击；长按不会自动战斗。危险战斗仍显示真实损失和战后生命。
- 开门、契约取舍、详察、战斗计算与分身调度在目标旁展开，不触发网页提示弹窗。NPC 对话带头像、逐字显现与分页；Space 先显示整句，再推进下一句。走开即收起。
- 每次进入楼层都有对应的场景入场和文案。右上主线可以点击定位；跨层回访明确提示 J 和灵息代价。
- 修缮 26 处守卫/钥门与真实奖励的关系，移除 10 道没有独立用途的重复门。可选守卫明确显示用途和胜利功德；无需清怪才能通关。
- 白衣无天可主动开启十三层善念南径，绕过正面守卫；五印齐聚后，十五层归根云廊可直达第一层。
- 金箍桥按真实岸向绘制；青蝉对应独立铁栅表现，还可卸开普通青色锁门（耗灵息，保留青钥）；分身上限、费用和高亮共用真实预览，驻守不再播放残留出生帧。
- 终局补给从首领身后移到可提前取得的守卫支路。地图修订为 levelRevision 6：旧档回到本层莲灯，保留属性、物品、已领取奖励与机关，不重复发奖。

当前复验：`node tests/engine-check.cjs`、`node tests/v4-rules-check.cjs`、`node tests/v9-rules-check.cjs`。PC 浏览器用 `node tests/v9-browser-acceptance.cjs`，对应 `audits/v9-browser-acceptance.json` 和逐张实机截图。它通过真实 UI 验证关键操作，并以合法公开行动衔接其间的移动；不等同于真人首玩评价。历史 v5–v8 回放不用于证明本轮修复。

## v7 地图、清晰度与目标提示

默认探索采用等比覆盖相机，不再把方形地图缩在宽屏中央、两侧铺远景。宽屏显示更多列、较少行，手机显示局部并随悟空移动；M才缩小整层规划。南沿入口如会被固定技能栏遮住，相机仅补偿最多1.5格不可走边界石墙，碰撞与地图坐标不变，不用装饰远景冒充可走地图。

普通提示绑定怪物、同道或机关的实际可见范围，带短引线，按位置选择左右上下避让；目标离屏时显示方向定位。普通提示没有窗头、关闭×或固定右上兜底。完整计算和长说明仍由玩家主动打开游戏卷册。

技能栏位于下方正中，有可读名称、图标、锁定和真实费用；触屏方向盘与它分层。行走/查看可点击高出格点的角色轮廓，神通则严格按格点选择，不会把北侧目标误认成悟空本人。

材质角色从原始生产图重建384×384帧，敌人和同道256×384，逻辑体量保持不变；动态实体和效果直接画入最终DPR上下文，不再先压进48px格缓存后放大。地形以384px四格材质缓存，像素套继续使用nearest。两套风格、规则与存档保持独立。

公开资料、产品准则和量化验收见 `docs/game-presentation-guidelines.md`；用户反例测量见 `docs/v7-baseline-audit.md`；具体建议、实施纠偏和最终状态见 `docs/v7-presentation-review.md`。

## v6 基础交互与双画境（保留部分）

左上仅生命、灵息和钥匙，右上层名、进度和工具；详细人物信息平时隐藏。M/F视野选择保持独立。玄金雾寺远景只用于标题和明确的整层规划，不用于填充默认探索地图。

普通通知、拾取、剧情和战前反馈不用网页式弹窗或遮罩：分别呈现为角落符纹、场景浮字、非阻断对白条和紧凑临战符签。符签直接显示真实预计损失和战后生命；计算细节与首领准备由玩家主动打开边缘卷册。短扫线、印记显现和对白笔触只用于状态变化，减弱动态时静态等价。重大路线选择仍先展示完整代价，由主动交互台确认。

**玄金神怪·三维古寺**：湿石、炭黑、古金、朱红披帛、玉灯，角色、同道、敌人、道具、建筑、地表、头像和效果由内置ImageGen生成的PNG接入。它是三维材质风格的预渲染图集，运行时仍为二维Canvas；不会宣称已有实时三维几何。原始素材、生产提示规格、图集与TA合同见 `assets/material/README.md`、`assets/material/prompts.json`。v7从原图重建更高分辨率，151个寻址ID含别名与独立头像，对应110组帧；9张PNG约12.66MB。

移动按真实步进插值；棒击按蓄势、定向前冲、命中和收势呈现，净生命损失显示在悟空上方。门、拾取、化蝉、分身与觉醒读取权威事件；跳过动画不会重复结算。角色伸出占格的可见部分也可点击选择，格点命中与屏幕投影保持一致。

## 青绿风格与关卡深化

选定美术为像素方案第二套 **青绿重彩·壁画浮世**。孔雀蓝云山、青绿瓦、朱红柱、奶白庭、贴金壁画贯穿场景、人物、门灯、道具、界面与觉醒。没有把整张概念稿贴到画布充当游戏；实际棋盘由独立角色帧、材质、机关与六章建筑资源绘制。

原始PNG、归一化图集、锚点与来源清单位于 `assets/mural/`。145个寻址ID包含别名，对应105个独立帧组；9张运行PNG约7.25MB。48px原生格渲染保留细节；脚点排序、透明遮挡、连续地表、地形缓存、真实机关开合、六组四帧效果、减弱动态与跳过均由表现层处理。详细TA约定见 `assets/mural/README.md`。

关卡深化保留十八层、敌人总数和资源总上限。新改动增加选择的用途与时机：

- 第2层：保留防御+2，或舍弃它打开定海铁侧门，绕过精英并放弃其功德。
- 第4层：原攻击晶移到真实铜铃嘴口，可现在承受法术，或配装后回访。
- 第8层：水魂/余毒守卫与横桥傀儡形成真实渡口；保留90生命，或舍治疗并花一黄钥开西缘栈道。
- 第17层：保留防御+4，或用它打开心炉烬北径；取得异宝仍受双装配位与副作用约束。

第5层三契、第11层三台两影、第14层救援取舍保留。全部18层的经卷有不同的规划问题与明确目标，不用增加墙长或怪物数量解释“内容更丰富”。研究来源、改前问题、预算和实际路线见 `research/level-depth-v5.json`。

## 透明规则

战损与实战共用 `TowerRules.battle`：攻击须破防，出棒数向上取整，普通敌人由行者先手；先攻、法术、余毒、反震与首领三相均明确展示。生命须严格大于总损失才获胜。守卫、钥匙、成长和道具不刷新。

六件法器最多同时装配两件，须站莲灯免费切换。攻击、防御、首棒、先攻、法术、反震、战利功德与神通代价的利弊全部进入真实预览。莲灯补灵息，不免费回生命。凝息珠可补息、换钱/生命，或留给最终三套准备。

v1–v4旧档保留。旧版大地图和本轮修订首次载入会安全回到本层莲灯，保留原属性、资源、选择及机关；当前修订存档保持原坐标。已领取的旧供给不会再通过新选择重复领奖。

剧情为受《西游记后传》启发的原创平行篇章；无相塔、五印和守塔分歧为本作设定。舍利数为16外在+悟空自身，十八层不等于十八颗舍利。

## 结构与验证

- `js/world.js`：18层作者地图、实体、路线承诺、研究落地与剧情。
- `js/engine.js`：唯一权威状态、纯战斗、机关/资源事务、回溯与迁移。
- `js/assets.js`、`js/material-assets.js`、`js/art-style.js`：两套本地清单、懒加载、风格事务与图集接口。
- `js/renderer.js`：全视口投影、脚点/遮挡/相机、两套材质、持续状态与TA效果。
- `js/ui.js`、`css/immersive.css`：角落HUD、非阻断对白、临战符签和主动边缘卷册；原风格CSS保留作主题基础。
- `js/audio.js`：本地合成配乐与音效，和美术动作设置独立。

当前浏览器验收入口为 `tests/v7-browser-acceptance.cjs`，完整冒险由 `tests/v7-campaign.cjs` 回放；界面/清晰度证据在 `tests/v7-*` / `audits/v7-*`。它沿合法公开行动推进，真实操作收集、配装、机关、战前确认、首领准备、觉醒、结局、存读档和风格切换，并截图检查。开发用Node/Playwright不属于游戏运行依赖。

v5及更早浏览器脚本与截图是历史证据，不能按旧模态选择器直接用于v6；引擎规则检查仍适用于当前未改变的规则。v5曾完成两条完整路线，避战路线实际通过四道新门、跳过四场指定战斗。最新改动与每步反思见 `research/immersive-v6.json`。

`audits/v5-independent-review.json`保留独立资源/状态检查；`research/mural-ui-reflection-v5.json`记录截图发现与修正；最终源图与实图对照见 `design-qa.md`。早期v2/v3/v4审计与图属于历史资料。自动回放不等于真人首次理解度、主观美术偏好或真实手机性能测量；本轮没有据此承诺通关分钟数。
