## 接入结果

`css/image-ui.css` 将资产作为可分段伸缩的框皮使用，边角维持约18–40 CSS px的实体厚度，中心随内容伸展。不是把整张图片按窗口比例随意拉扁。生成图片不参与点击区域、条件判断、支付或奖励。

- **截图里的当前要事**：半透明绿矩形换成铜木牌。主目标、原因、关键词和标记动作仍由实时旅程数据提供，文字排在暗绢内，牌匾不携带烘焙文案。
- **战前与目标信息**：白纸木框经签承接敌人、宝物、门和机关。损失、战后生命、成长临界和主要动作继续实时重算；公式仍按需查看。
- **对白**：木卷端、铜件与暗绢横卷，保留说话者、短句、当前要事和继续 / 收起。撤去旧纯色背景与裁切，避免生成图外面仍套着网站式矩形。
- **莲灯与取舍**：每份供签有自己的木板、铜夹和纸面，收益 / 费用 / 缺口由引擎提供；标题与返回区使用横卷，普通次操作使用铜木轨。选择只比较，明确确认才结算。窄 PC 面板收紧无关留白，保持角色可见。
- **其他重复阅读面**：物品说明、详细楼层经卷、当前任务、图鉴书页、推演结果、章回预览、存档和指引使用同一经签材质。部分整场暂停与叙事背景沿用既有构图，不把每个屏幕都另加一个大型浮窗。

四张共约10.33 MiB，原图完整保留在工作区。`js/ui-skins.js` 在开局前预载，真实进度并入现有资源计数；两套画境共用这套古寺实体轮廓，原地图、人物和画境仍分别呈现。
