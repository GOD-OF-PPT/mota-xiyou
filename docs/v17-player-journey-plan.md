# v17 连续游玩体验实施方案

2026-10-23。目标：让玩家在同一场景中连续完成“观察目标 → 比较代价 → 行动 → 看见结果 → 理解下一步”，统一首段体验并贯通十八层共用系统。

## 体验约定

- 当前要事只有一个主要入口。入层、常驻目标、场景目标、手记引用同一份由真实状态计算的目标；说明这一步的用途，按需提供操作帮助。
- 前段从身边可取得的攻击灵晶开始建立成长认知，再辨真、看战损、取第一枚外舍利、主动上楼。推荐不强制，不奖励测试资源，不把所有怪物标为必打。
- 定位只显示目标与可安全行走的路线，不代替移动或战斗；远处目标进入全图比较，保留悟空位置。被门、守卫、机关、断口阻挡时先指向真实前置条件。
- 查看、比较、行囊、剧情、技能均不偷跑世界行动。普通行动只用短场景反馈；关键剧情保留一份演出，结果与下一步在结束后衔接，避免演出之后又弹同一段对白。
- 角色、场景与界面的视觉标识分工固定：目标使用金色地面标记；可走路线使用连续青线；成本、结果与锁定说明使用相同措辞。保留 v14/v16 原生清晰度与地面衔接。

## 分阶段实施与验收

|阶段|实施|验收|
|---|---|---|
|P1 统一状态模型|新增只读旅程模块，解析主线、当前前置条件、阶段、操作和原因；提供角色用途与行动结果模型|18 层目标来自真实实体/地形；不凭坐标造目标；读档、回溯、重做后重新计算；引擎、地图和资源规则不变|
|P2 引导与决策|收束重复目标；初段以附近成长引入；目标定位显示安全路线；战前自动给出一条真实可达成长机会，仍可自由迎战或绕行|新游戏不依赖帮助页；免费查看不花资源；成长前后战损有实数依据；定位不移动；路线不穿守卫或封门|
|P3 行动与反馈|结算后的状态差量组成简短结果，配上一条新目标；普通拾取/开门/机关/战斗共用反馈入口|预览无结果、失败不报成功；一次行动只有一次资源结算；结果对应实际变化，载入和回溯不伪装成新奖励|
|P4 叙事与节奏|路过碑文用短回响，主动交谈才展开；关键演出结束后回到当前目标，移除重复对白；保留明确入层确认和跳过|查看、对白、菜单、入层、演出期间输入边界一致；常用神通不反复打断；关键剧情不丢失且全文可在手记查阅|
|P5 场景与信息层级|地图标记与引导同源；已完成目标立即撤销；菜单关闭后回到原比较；明确标识可选战斗与主线前置|双画境、1440×900/1989×1113/1280×720 代表截图逐张原尺寸复核；目标、人物和操作不互相遮挡；普通探索中心留给地图|
|P6 连续体验验收|从新游戏连续通过首三层，用真实鼠标与键盘执行全部行动；补充全十八层合法行动与既有交互回归、离线检查|前段不加载中间存档、不注入状态、不传送；记录实际目标、比较、结算、换层与首次神通；完整流程、双结局、两套画境及 file:// 仍可用|

## 执行顺序与交付

按 P1 → P2 → P3 → P4 → P5 → P6 实施。发现前段阻塞先修复再继续；最终以当前源码、浏览器结果和原尺寸截图交付，不以实现行数或测试数量替代体验判断。实施证据持续记录于 `docs/v17-player-journey-review.md`、`research/player-journey-v17.json`、`audits/v17-final.json`。

本轮完成可实现、可观察的连续体验。外部新玩家的盲测、主观乐趣和长期节奏不能由代理回放代替，不作为已经取得的研究结论。
