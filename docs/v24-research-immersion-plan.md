# v24 调研落地与新增页面的游戏化实施方案

2026-10-24。本轮加入现有持续目标。依据 [相近游戏玩法与反馈调研](v20-similar-games-research.md)，承接 v23 的组合遭遇、独立挑战和合法路线，集中修复新增界面像软件操作台的问题。v23 真人观察门槛保持待验，不以本轮界面验收代替。

## 调研映射与取舍

|调研依据|已有结果|本轮实施|
|---|---|---|
|Tactical Nexus：可比较局面与低成本重试|短程推演、独立试炼、资源向量比较|将比较结果收束为可解释的生命、钥匙与补给取舍；目标选择直接可见，资料按需展开。|
|DROD RPG：局部问题需要完成感|章末结果、后段因果、试炼达标|试炼完成使用归卷仪式与真实资源结果，清楚衔接重走、记录、返回。|
|Desktop Dungeons：表现保护信息识别|精确战损、双画境|新增页面采用同一游戏材质与章回场景图，装饰避开文字、数字和主要操作。|
|DungeonUp：重复执行与隐藏前提增加疲劳|熟路快行、公开代价|减少重复说明与下拉表单，选中即展示目标与代价；修复同页更新后的焦点和滚动丢失。|
|Into the Breach：公开目标支持不同决策|八层、十一层各两目标|用可选题签表达目标差异；预览只读，明确入境才开始，不增加随机性或永久奖励。|

五款游戏、十条评论只支持设计假设；不补写未经调查的竞品事实或乐趣、留存结论。

## 视觉与交互约定

沿用 Canvas / DOM。玄金画境使用暗绢、铜金、朱印；青绿画境使用青绢、石绿、淡金。主标题以衬线书卷字体表达，资源和按钮保持清晰横排。优先复用现有本地场景资产，以少量渐变、线条与光晕建立层次，不放大低清小图。

推演为灯前书卷，保留三步边界与真实对比；章回前缘使用时间线，确认回退仍明确说明范围。试炼为两幅章回入口，公开目标使用直接选择的题签，起点和完整规则可展开；完成与记录保留资源向量及规则分组。对照试玩为独立入境页，观察者设置收拢，任务与入境顺序突出，不移入正式游戏 HUD。

翻卷、题签点亮、结果显现只在状态改变时发生，约 180–450ms；减少动态时关闭位移、旋转和持续动画。切换页面和重复点击不播放奖励、不重复结算。Esc 收卷，Tab 留在暂停体验，原生选框、文字输入与方向键正常工作；退出后恢复地图焦点。

## 实施与验收顺序

1. U0：冻结受影响文件，保存当前代表画面，核对数据和存档边界。
2. U1：推演、法器比较、章回恢复、此行所得统一书卷结构，减少信息噪声并修复焦点。
3. U2：试炼选择、结果与记录重做；保留解锁、同条件比较、退出主线和旧题目版本。
4. U3：对照试玩入口的场景、题签、入境动效；编号、轮次、目标和存储隔离保持可用。
5. U4：PC 1280×720、1440×900 与宽屏，两套画境逐张原尺寸截图；真实鼠标/键盘检查目标选择、只读推演、换装、恢复确认、试炼往返、刷新和离线。检查减弱动态、长文本与输入边界；不重复与界面改动无关的全塔求解。

十八层、确定性战斗、有限资源、双方画境与文件直开不变。主线与挑战的引擎规则不因装饰改变；需要试玩状态时使用既有合法行动生成的存档，不以状态注入证明路线。

每步的实际结果写入 `docs/v24-research-immersion-review.md` 与 `research/v24-progress.json`。功能和视觉通过后本轮实施可交付；真人偏好与 v23 的 S5 观察继续单列。
