# 大圣：舍利魔塔 · 场景、界面、动效与TA准则

适用版本：v10 沉浸式 PC 交互。当前具体准则与验收见 `docs/v10-immersion-plan.md` 和 `docs/v10-immersion-review.md`；下文保留 v7–v9 来源与原则记录。调查日期：2026-10-22。此文先整理公开来源，再将其转为本作准则和可见验收条件；数值中明确标为“本作”的部分是产品决策，并非引用资料的原文要求。

原有18层地图、确定性战斗、有限资源、双画境和无构建运行约束保留。用户要求优先：探索地图铺满屏幕、提示在目标周围、技能位于底部中央、禁止网页式提示弹窗。Game Studio 对默认界面布局的建议不能覆盖这些要求。

## 本作准则与验收尺度

### G1 场景先于框架

探索模式由真实地图铺满视口。采用等比正方格和覆盖相机，宽屏可显示较少行、竖屏可显示较少列；镜头随悟空和定位目标移动。地图之外的远景不能计入可玩地图覆盖。M是明确的整层规划模式，允许缩小看全局；F返回探索。

本作验收：常规探索的21格真实地图投影覆盖≥99.9%，边缘缺口≤1 CSS像素。禁止拉成长方格、增画虚构可走格，或用全屏canvas矩形替代这个测量。

南沿安全构图例外：合法入口位于第20行时，固定底中技能会遮住悟空。为同时保持可读尺度、底栏位置和脚点安全，镜头可额外下移最多1.5格；新露出的只允许绘制引擎 `getTile()` 返回 `#` 的不可走边界墙带，不能显示远景或伪造可走区域。验收分别报告21格作者地图覆盖、实体边界墙覆盖和远景覆盖（应为0），不把墙带算成可探索格。此例外来自实际入口截图，不修改地图、碰撞、路线或存档坐标。

### G2 角色清晰度按有效像素和最终链路判定

分别记录图集帧尺寸、实际alpha内容范围、显示体量、DPR和采样次数。材料套人物不得先进入低分辨率世界缓存。高清图集应从原始生产源图重新取样，保持共享比例与脚点；不得把旧96px帧放大后称为新增细节。

本作验收：2525×1208探索中，角色有效源像素相对CSS显示倍率目标≤1.05；另报告DPR2物理倍率，不能虚称其为物理1:1。原始截图100%观察脸部、头冠、红巾、兵器和怪物轮廓。轻接触影、受控边缘光用于与地形分离，不能全局锐化、厚白描边或发光来掩盖细节不足。

地形缓存按源材质分辨率取样，图集的物理分辨率与世界纹理周期分开。源帧扩大四倍时，角色的逻辑大小、碰撞与锚点位置不能跟着扩大四倍。

### G3 提示必须属于目标

普通敌人、人物、门、机关、神通目标的提示锚定当前渲染帧的目标范围。短提示只呈现名称、规则结果/真实代价和一个当前动作；带尖角或短引线表达归属。去掉网页窗头和关闭×。目标详察、战斗公式、临战准备与路线契约在原目标旁展开；行囊、人物、手记与设置为完整游戏画境；修心与契约在场景中展开。不得沿用长侧栏。普通通知和剧情不打开卷册。

本作验收：常规气泡与目标可见范围最近距离≤max(32px,0.5格)；保护目标及悟空脚点半径max(12px,0.18格)。选左右上下及斜向候选位置，避HUD、技能、对白和触控区。镜头移动时同步跟随，不用固定右上兜底。目标离屏时暂隐或显示可点击的边缘方向标，不能制造脱离目标的固定卡片。

### G4 技能栏下方中央，动作可预期

按用户指定放在底部中央。图标与名字共同显示，当前模式、未解锁和灵息费用明确；触控动作区至少44×44 CSS像素是本作的操作标准。技能说明不依赖悬停；键盘1–5和触摸同样可用。

本作验收：2525×1208、1440×900、390×844、844×390中，技能栏中心与视口中心横向误差≤2px；避开触屏方向盘，最下方保留安全区。气泡与对白不能使技能不可点击。

### G5 信息分层，规则始终透明

常驻只保留生存/资源摘要与位置入口；C、I、J等按需展开。临战气泡保留真实预计损失与战后生命。首次接触只预览；松开方向键后再次按同方向，或明确新按 E / 点击迎战才结算。系统产生的 key repeat 和 Space 不替玩家确认。取消或查看详情均免费。

文字不能为维持小框而逐字挤列。底部技能名、动作与代价要能在正常截图比例阅读；重要数字与背景对比≥4.5:1作为本作保守目标。复杂规则只沿一个方向滚动，不使主动作永久离屏。

输入目标须服从行动语义：行走/查看可按可见角色轮廓选中实体；架桥、化蝉、分身必须命中真实格点，不能被伸到上邻格的角色身体拦截。判断视觉点击是否准确时要同时覆盖这两种情况。

### G6 动效说明因果，不抢控制

移动由真实位移插值；普通战斗表达一次完整的蓄势、出棒、命中、收势，避免逐棒长演出。生命损失在悟空处，敌人受击与消散在敌人处；拾取从物品到角色，开门体现门扇/材料，神通标出真实来源与目标。高亮不暗示虚构伤害或额外资源。

本作时长起点：目标提示入场120–200ms；普通行动350–650ms；重大舍利觉醒可更长但随时跳过。它们是产品节奏起点，不是外部指南的固定值。持久机关状态由真实state绘制，动画结束、切风格、读档后仍可辨认。

减弱动态只显示静态确认；关闭扫线、位移粒子和镜头惯性。演出只读已结算事件，跳过、换风格或相机移动不再次扣血、扣钥匙或发奖励。

### G7 用反例与完整流程验收

保存用户同视口反例、当前代码身份、改后同视口和局部像素比较；实际打开截图。本轮按用户要求固定 PC，覆盖双风格、1440×900 与 2525×1208、镜头边界、技能点击、读档和减弱动态；不把历史手机结果当作本轮验证。稳定后以合法轨迹完成一次18层关键交互与双结局；后续只复核新差异。

“无控制台错误”“canvas占满”“无aria-modal”“测试退出0”均不能独立证明符合用户视觉要求。审查表必须写出具体提升、反例修正和剩余边界。


## v9 补充：用途、叙事与权威状态

- 门必须守护可见收益、控制必要通路或缩短实际路线。不能仅因它带有门的图标就保留；检查封门前后的真实连通图。
- 允许可选战斗。守卫应说明守护目标或公开功德收益，不能把清空全图当成唯一进度。终局补给必须能在首领前取得。
- NPC 的承诺须有地图或状态兑现。白衣引路按真实 quest 开门；帮助不靠一段台词自称生效。
- 楼层入场只承载这一层的场景与主题，非阻断、定时退场；新进度、读档或主动交谈不继承旧层入场。
- 断口、铁栅、钥门、阵眼须分别可辨。桥的方向来自通行轴；青蝉只显示一个往返主体；分身驻守由稳定状态绘制，出生效果不常驻。
- 目标提示、可用高亮和动作结算应读取同一套能力预览，包含解锁、距离、费用与驻守上限。
