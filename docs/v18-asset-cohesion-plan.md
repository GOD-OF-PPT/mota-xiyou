# v18 素材与场景统一修复

2026-10-23。按用户已确认方案执行；目标为干净裁切、可靠接地点、统一比例、足够有效源像素与可辨识场景关系。继续使用 Canvas、十八层、确定性战斗、有限资源、双画境和离线直开。

## 阶段与通过条件

1. 固定合法行动取得的首层、庭院、机关检查点，记录同视口、DPR、镜头和资源。保留前图。
2. 为原始拼图逐件登记区域及主体、可保留附件，隔离相邻物件；清理不能误删合法武器、灯笼、飘带。原图保持只读。产物可重复生成。
3. 角色按脚底、道具按底座登记真实接点；统一绘制、阴影、深度、点击范围。缩放依据最终游戏尺寸，不由碎点或武器长度决定身体比例。
4. 恢复角色和建筑原生像素，高清重制仍不够的重点素材；按实际绘制尺寸和 DPR 检查有效源像素，并原尺寸检查结构与透明边缘。
5. 取消通用独立石板观感，按各类物件自身底座建立接触；NPC 标记与主目标区分，轮廓不挤占相邻交互对象。
6. 检查代表 PC 视口、DPR 1/2、近观/全图、双画境、墙体遮挡、真实点击移动、保存恢复和断网文件直开。全十八层由合法行动重放；连续前段使用鼠标键盘，不注入资源、不传送。

首层“小怪靠墙”和“石碑—莲灯—NPC”优先作为样区。其余同源素材沿用同一登记流程。源像素检查和自动回归不能单独证明美术质量；逐张原尺寸复看并记录剩余差异。
