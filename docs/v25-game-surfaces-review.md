# v25 全部弹出界面的实现与验收

2026-10-24。本轮按 [调研与方案](v25-game-surfaces-plan.md) 改造现行版本。覆盖17类可操作的暂停视图，以及场景签页、修心、取舍、对白、入层、神通和最终布阵等独立层。此前只改部分新页面的问题已扩展到旧界面。

## 调研怎样落实

六项来源的正文均已读取，定位与限制见 `research/ui-v25-sources.json`。Dead Space / Resident Evil 6 的对比用于检查信息与对象、动作的一致性；Ghost of Tsushima 的引导案例用于保留清楚目标、按需打开完整信息；Xbox XAG 101 / 113 / 117 与 Game Accessibility Guidelines 分别约束文字、焦点、动效和点击目标。

这些来源提供设计依据，不证明所有玩家偏好相同，也不意味着本作通过了完整无障碍认证。未使用竞品截图作为游戏素材。

## 已改造的界面

|界面|构图与实际行为|
|---|---|
|行旅|休息中的行者与去路题签，主要目的与少用操作有层次。补齐此前在完整暂停菜单中不可直接到达的“舍利莲阵”和“重启冒险”。|
|行囊|布囊、六器位置、两件佩戴位和一张物品签页。玄金使用现有高清悟空立绘；只查看不消费，使用 / 佩戴保持正式结算。窄 PC 面板优先露出使用动作。|
|人物|人物画轴与修为题记；有效攻防、生命、灵息、心印与当前行装仍对应正式状态。|
|画境|两幅可展开画卷，当前画境有文字与朱印。改变表现不改变资源或机关。|
|因果簿|当前要事使用可读纸笺；十八层收束为六回卷册，仅当前回默认展开。已抵达、可回访、乘云代价仍保留；未抵达楼层不泄露名称。|
|敌情|从整页重复战损卡片改为守卫索引与单个图鉴书页，展示实际守卫资产、规则、属性、预测与一个返回场景的主动作。查看和切换不会迎战。|
|舍利莲阵|保留十六外环与中央空位，状态和楼层定位使用题记组织；实际拾取仍在地图发生。|
|指引 / 声音|六招图解、按需完整规则与独立声音 / 演出页；标准、简洁、减弱动态与原有音频选项仍可操作。|
|读档 / 重开|独立手动与自动前缘如两份存卷；读取范围清楚。重开先说明自动前缘会替换、手动前缘保留，再确认。|
|推演 / 试炼|沿用 v24 的三步与公开目标，用统一材质、题签和落印收束。规则、起点、同条件记录、退出主线合同保持。|
|莲灯|供签分别承载图标、成长、价格和缺口，撤去外围窗口框。调息和奉珠是次级动作，结果仍在正式结算后显示。|
|两项 / 三项取舍|纸签直接说明获得、支付、机会成本。选择只比较，独立确认才结算。窄面板的三项内容局部滚动，键盘选择会把焦点带回可见区域，确认与返回保持可用。|
|战斗 / 门 / 机关 / 对话目标|使用贴近对象的纸签，真实战损优先、公式按需展开。修正换纸底后旧深色主题的浅字继承，主动作、阈值和战后生命保持可读。|
|对白 / 回响|对白底衬与控制统一，保留短句、当前目标和收起规则；普通反馈不转成网页弹窗。|
|入层 / 神通 / 最终布阵|纸笺目标、仪式标题和明确继续 / 确认；沿用已结算事件与实际分相演出，跳过不重复扣费。|
|归真 / 结局 / 力竭|叙事仪式采用不同于管理卷册的布局。两结局、战前恢复、失败与回溯语义保留，不由外观回调发奖励。|
|楼层经卷 / 载入反馈|经卷采用同一纸底与墨色；画境载入维持清楚进度。旧隐藏式选择节点不作为新的游戏入口。|

楼层经卷展开时，暂时收起内容重复的常驻要事；详细目标仍在纸笺中可见，合卷即恢复常驻指引。避免窄面板中两层提示互相遮挡。

17类暂停视图的明确标识为：`menu`、`inventory`、`character`、`style`、`journal`、`bestiary`、`collection`、`guide`、`settings`、`load`、`restart`、`defeat`、`awakening`、`ending-choice`、`ending`、`planning`、`trials`。共用处理不再依靠同一默认书页去区分所有目的。

## 交互与动效

暂停、场景仪式、叙事层保留各自的输入边界。Esc 返回原场景或原未确认取舍；Tab 留在当前体验；原生选择和输入可正常使用。三项纸签在窄面板中用方向键切换时会滚入视野，避免焦点落到不可见内容。

翻卷约260ms、物件选中约200ms；强动效保留给原神通和三相演出。系统或游戏减弱动态设置关闭非必要动画。没有持续晃动的阅读背景，也没有把支付、奖励或战斗放进 CSS 动画结束回调。

## 原尺寸视觉复核与当前页面

代表截图逐张打开原尺寸查看，重点检查纸底墨色、实际数字、按钮、单一主动作、控制区和滚动边界。登记的代表画面见 `audits/v25-final.json`，包括窄 PC 供签 / 三选一、行囊、人物、手记、敌情、入层、最终布阵和结局。

用户原来的 P01 v22 对照页只读查看并保留。另建 `UI25` 独立进度，用正常开局核对新版的莲灯和行囊，并保留为可直接试玩的预览；不是主线解锁注入，也不是登记的真人观察。

当前游戏：`index.html`；独立新版预览：`playtest-v23-new.html?participant=UI25&round=1&task=first-three&objective=explore&art=material`。冻结 v22 的原对照页面维持原样，避免失去比较基线。

本轮完成实现与技术 / 代表画面验收。真人对美术偏好、理解、疲劳和复玩的判断仍单列；没有虚构参与者、原话、比例或时长。窄 PC 面板已专项验证，手机全面适配和广泛浏览器兼容未纳入。
