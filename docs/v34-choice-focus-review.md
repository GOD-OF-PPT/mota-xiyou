# v34 取舍确认集中在同一张卷轴

2026-10-26。依据用户“百锁三契”截图：主确认和退出操作分别占据两条厚重横栏，提示重复，灰色确认又无法说明当前状态，玩家难以找到下一步。

## 修改结果

- 取舍的说明、预计变化、主要操作、退出和行囊统一置于一张底部卷轴。移除原说明板和页脚各自的框皮、重复的 Enter 提示。主要动作使用朱砂底与金边，退出、行囊只保留次要文字操作。
- 待确认时显示“已选某契 · 等待确认”，同一行右侧明确提供“确认：某契 / Enter”。选项、数字和方向键仍只比较，确认前不扣费。
- 条件不足时在主要动作旁说明缺口；比较其他契台时可标记正确契台，不会异地定契、扣费或发奖。
- 已定契时以真实已选路线为准，显示“已定契：某契”，不再显示重复确认或“尚未生效”。其余选项显示封存，浏览它们不会改变既定路线。奖励未领时主要动作为“标记北匣位置”；已领时明确“奖励已领取”，主要动作改为“返回探索”。
- 窄 PC 窗口及长说明只滚动签页，确认卷轴始终可见。调整窗口或切换选项后保持所选签页标题可见。Tab 跳过隐藏按钮；行囊返回仍保留未确认选择；莲灯的原交易流程保留。

本轮复用已有游戏框皮，不增加软件式弹窗。正式入口、新版试玩的 UI 和取舍反馈版本更新到 v34；引擎、地图、有限资源、十八层主线、存档格式及冻结基线不变。
