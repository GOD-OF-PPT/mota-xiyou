# v19 莲灯文字溢出与信息层级修复

2026-10-23。针对用户红框中的莲灯交互区完成定向修复。保留场景内仪式、原交易规则和两套画境。

## 根因

莲灯与取舍共用 `#altar-ritual`。两项取舍会留下 `data-choice-count="2"`，回到莲灯时未清理；该属性对应的 CSS 又没有限定 `data-purpose=choice`，使“1–2 / 方向键比较 · Enter 确认”错误地挤入莲灯底部。原布局还把说明、资源数量和控制按钮压在同一段区域，价格强制不换行、中央选项上移，大椭圆背景无法稳定承托这些信息。

修复前通过真实鼠标打开两项取舍，再返回合法路线取得的莲灯检查点，复现了残留属性、错误提示和横向溢出。证据：`audits/v19-lotus-before.json`、`audits/v19-before-reported-lotus.png`。自动检查点有 18 金、1 珠；它是完整合法路线所得状态，不声称与用户截图的 9 金数值相同。现有 Chrome 的 9 金、1 珠状态另行实机确认。

## 改动

- 莲灯显式清理取舍选项数量；取舍专属样式限定交互目的，专属帮助也随模式切换。
- 标题与“功德 / 凝息珠”独立一行；三项修行对齐，名称、收益、价格、资金缺口分别显示。
- 调息与两项奉珠各自显示用途、代价；规则、实际结算反馈、离开与行囊、键盘说明各有明确区域。
- 背景改为边缘渐隐的场景签页，按实际内容承托文字；列宽允许收缩，反馈允许正常换行。
- 莲灯采用与取舍相同的场景避让计算；小窗口也避开悟空及其头冠轮廓。交易重绘后保持可用按钮焦点，已失效的动作返回离开按钮。
- 入口资源版本更新为 19。

修改文件：`js/ui.js`、`css/experience.css`、`index.html`。备份：`.backups/ritual-v19/`。
