# v26 高频界面的实体材质与接入

2026-10-24。用户反例是“此行要事”的半透明绿色矩形，缺少游戏物件的厚重感，读起来像网站浮层。本轮明确使用内置 imagegen 生成真正的界面美术资产，再接入当前游戏；不以另一轮 CSS 金边或概念图替代。

## 资产与用途

|资产|实体设计|消费界面|
|---|---|---|
|行旅铜木牌|厚木芯、旧铜包边、压暗绢面，装饰集中在边缘|当前要事、即时回响、读档 / 规则短提示|
|察物经签|厚旧纸、铜木书夹、边角磨损，内页安静|战前、宝物、门、机关、楼层经卷和完整账目|
|塔中对白横卷|厚实卷轴两端、暗绢文字区，横向比例|短对白、技能标题和暂停页章回信息|
|莲灯供签|悬绳铜扣、硬木背板、旧绢题签|修心三项、二选 / 三选取舍、物品说明和主要行动|

每张资产独立生成，真实透明边缘、无文字、无数字、无预绘按钮；中心保留可排版区域。文字、价格、真实资源、选中与焦点由 DOM 继续显示。资产用边框切片或可伸缩中心接入，避免整张背景拉伸后角饰变形。

玄金与青绿画境共用可辨认的物件轮廓，通过原画境色调与局部色值兼容。装饰不遮住文字、不占用额外大面积地图。标题和动作保持中文横排。旧 v22 对照页冻结。

## 实施和验收

1. 保存每张完整生成提示、原始文件路径、工作区资产与哈希，检查 alpha 与可读区域。
2. 替换高频目标、战前、对白、修心 / 取舍和回响等纯色容器，并使原有暂停卷册使用匹配材质。
3. 不改战斗、资源、存档、关卡、解锁或费用合同。焦点、返回、明确确认、减少动态保持。
4. 当前 PC 窄面板、1280×720、1440×900 的两画境逐张原尺寸复核；真实选择、费用一次结算、刷新和离线定向检查。

最终交付包含工作区 PNG、提示记录、接入代码、截图与验收报告。图像采用内置 imagegen；不启用 CLI/API 备用路径。
