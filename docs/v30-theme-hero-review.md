# v30 肉鸽提示词、画境解锁与玄金主角

2026-10-25。实现用户本轮三项要求，当前魔塔保持既有十八层、有限资源与确定性战斗。

## 肉鸽游戏开发提示词

[`xiyou-roguelite-development-prompt.md`](xiyou-roguelite-development-prompt.md) 是可直接复制到新任务的完整提示词。沿用无天黑莲、悟空、乔灵儿、十六外舍利、五重心印、自身无骨舍利和双结局，设计独立的俯视动作肉鸽《大圣：无相轮回》。包含单局 / 元进度、随机种子与可达性、三条构筑、四神通、有限资源、救援影响、三相决战、画境解锁、存档、离线与分段实施。

提示词将本会话的实际问题写成明确约束：场景交互与全暂停管理分开、短对白与当前目标、人物单一入口、先比较后确认、文字真实边界、固定框皮内滚动、出生空地、同镜头光照与落脚、素材按原生密度注册、演出读取一次结算、真实合法通关和逐张原尺寸检查。它是新项目的开发输入；本轮没有将当前项目改造成肉鸽。

## 通关才解锁青绿壁画

- 默认玄金古寺。未通关时画境页只显示玄金，旧下拉入口与试玩准备页也屏蔽青绿选择。
- `TowerStyle.set()` 在加载前检查奖励，旧偏好或 `art=mural` 不能提前切换或预载另一套角色图集。
- 任一完整主线结局均可解锁。奖励单独存为 `dasheng-style-unlocks-v30`，不占用战役资源；刷新、新冒险及回溯保留已获得的奖励。选择新画境仍是玩家的主动操作，通关不会强制切走当前画面。
- 旧自动 / 手动通关档通过当前引擎的真实载入校验后承续奖励，存档原字节不被覆盖。仅到达末层、只有胜利标签或独立试炼均不授予奖励。
- 新版独立试玩保留已选画境，刷新不被入口的初始参数覆盖；各匿名试玩与正式进度的奖励、偏好仍隔离。

冻结 v22 原卷及其资源作为历史对照保留；当前正式入口和新版试玩执行 v30 规则。

## 玄金主角重设计与接入

此前人物的高亮金甲、鲜红披帛与夸张冠翎，使主角像一张独立插画贴在灰石地图上。本轮确实调用内置 ImageGen 生成两个原始 RGBA 文件，并接入游戏：

|文件|用途|
|---|---|
|`assets/material/hero-v30/wukong-seed.png`|统一的角色种子，亦为剧情大像来源。|
|`assets/material/hero-v30/wukong-atlas-raw.png`|一次生成的四方向、每向四姿态，共 16 帧。|
|`assets/material/hero-v30/wukong-atlas.png`|技术注册后的运行图集。|
|`assets/material/hero-v30/wukong-portrait.png`|同设计的头像裁片。|

材质改为炭黑层叠旧甲、磨损古铜边、深褐毛发、低饱和暗朱布料；保留悟空、冠饰、尾巴与金箍棒的辨识度。镜头与左上软光匹配古寺，披帛与冠翎收敛，使用已有场景接触阴影与投影。

原始生成图均为 1254×1254，真实透明。技术脚本根据 16 个主体的实际分布裁片，没有假定生成图必为完全等分网格，以免切断第三、四行冠翎与出棒。共享原生缩放为 1；运行的 512px 单格包含脚点留白，不代表每个角色有 512px 的有效细节。每帧 alpha 边界、鞋底接触、源裁片、共享缩放与哈希写入 `research/hero-v30/registration.json`，完整提示与原始生成路径写入 `research/hero-v30/prompts.json`。

地图、分身、行囊、人物页、HUD 肖像和剧情大像均使用新设计。碰撞、坐标、能力费用、敌人属性与关卡未改；原英雄素材保留供历史对照。
