## 实施范围

运行改动集中在 `js/ui.js`、`css/ui-layout.css` 与经卷 DOM。没有改写战斗公式、地图、资源总量、存档格式或双画境解锁条件。正式入口和新版试玩使用 UI / layout v43；v22 冻结基线保持原样。

没有重新引入最终战动画。最终战和静态胜利绘卷继续遵循 v42；分身的管理、阅读和暂停均不额外扣费，实际部署仍由原引擎结算。也没有用补送资源掩盖路线问题。

## 保留边界与继续维护准则

本轮覆盖 PC Chrome、两套画境、离线直开和两类试炼，并实际走通主线及双结局。未声称穷尽所有玩家路线、证明主观可玩性最优、完成新玩家盲测或音效听感验收。移动端与全浏览器矩阵继续按项目要求延期。

此后新增入口必须同时检查进入、退出和被其他页面覆盖时的输入归属；动作名称必须描述实际行为，不能用“部署”暗示免费调度，也不能在游戏已完成时提供无效的使用按钮。免费预览与真实结算分别验收，防止只检查按钮存在或只检查引擎拒绝后就认为交互正确。
