# v28 出生点与莲灯重叠修正

2026-10-24。用户截图中悟空躯干与莲灯模型重叠，出生处难以辨认。

原因是 `TowerEngine.initialState()` 一直把第一座莲灯的坐标当作出生点，未采用地图已有的 `floor.spawn`。第一层莲灯位于 `(10,18)`，地图预留的灯前空地位于 `(10,19)`。这是真实站位重合，不是 PNG 模糊或遮挡排序造成。

当前旧存档不被强制搬动或重置。已创建的前三级试玩若保存了旧出生点，按其原始来源继续读取；只兼容这次坐标修正对应的已知旧起点哈希，其他题目变化仍保留原有校验。新版首轮试玩采用新出生点，冻结 v22 对照页字节保持不变。
