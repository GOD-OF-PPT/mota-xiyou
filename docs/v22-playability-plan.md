# v22 可玩性实施方案

2026-10-24。依据 v20 当前可玩性分析、相近游戏研究及 v21 已交付边界。保留十八层、原地图资源总量、确定性战斗、双画境、F 交互 / R 归位及离线直开。此次不是外部玩家实验，不以动作数量推断乐趣或留存。

|原问题|本轮实施|验收结果要求|
|---|---|---|
|G01 / G06 重复执行、补息回跑|已走过且无事件的安全路段自动加快；未走路段保留原节奏，接近实体与决策停顿。走路仍逐格经过引擎，不传送、不代打、不自动开门、换层、施法或取舍。|同一合法路径逐格结果一致；仅熟路无事件段更快；可用按键/点击中断。|
|G02 长期恢复|六章首次踏入与最近八次重大取舍前的完整前缘，随存档持久保存；读取前先展示回退范围，再明确确认；回退替换全状态、丢弃后续分支并保留一次返回原进度的入口。|刷新、导入、撤销/重做和跨章恢复不复制奖励；旧档从当前局面开始记录，不伪造早期记录；独立手动档不被覆盖。|
|G03 短程比较|玩家从地图标记最多三个本层目标及明确动作；只读模拟实际行走、战斗、拾取、开锁、神通、潮位或取舍，给出逐步收益/费用、净变化和阻断原因。|沙盘复用公开引擎规则；沿途其他资源与机关不自动处理；不替玩家行动；顺序改变可影响真实结果。|
|G04 / G06 组合题|把已有八层渡灯、十一层双影、十四层护送、十七层燃髓组织为带明确机会成本的局部问题；支持把相关动作纳入同一推演，证明原有不同路线而不加同形机关。|至少验证八层和十一层两种不同公开代价的合法解；后段真实取舍和可达性纳入回归。|
|G05 配装收益|推演同一目标序列下当前已拥有的零/一/两件组合，显示总战损、功德、技能费用及负作用。仅站在莲灯可确认整套换装。|未拥有装备不可借用；比较免费、不改正式状态；换装确认一次、可撤销、最多两件。|
|G07 阶段结果|具体提示通路、救援、留钥和驻守改变，保留最近阶段结果供主动回顾；主目标持续可见。|结果取自正式状态变化，不由推演生成，不重复领取奖励。|
|G09 性能与信息识别|记录 PC 冷启动及三步/全组合推演耗时；有实际瓶颈再优化。|保存设备/浏览器、样本和测量边界；不承诺未测得的速度或留存改善。|

G08 独立章节挑战和同条件本地排行依原分析放在核心闭环之后，本轮不加入跨局刷属性。新玩家理解度、疲劳、愿意再玩等仍需人类试玩，功能验收不替代这些结论。

实现顺序：独立恢复与只读推演模块 → 快行和暂停界面接线 → 具体阶段反馈 → 合法动作模型与 PC 输入检查 → 双画境原尺寸逐张复核 → 离线与旧档回归 → 更新试玩页和验收文档。
