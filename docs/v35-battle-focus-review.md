# v35 战前信息分层与明确迎战

2026-10-26。依据用户铜面罗汉截图，原签页把战损、力竭警告、攻击临界、筹算、规则和推演放在同一层级，多个细线按钮难以区分主次。

## 当前行为

- 默认只保留敌人名称、简短身份 / 胜利功德、本战胜负判断、预计损失、生命前后变化和一个主要动作。移走默认展开的攻击临界、附近成长建议及多个同级操作。
- 可胜时提供“迎战 F”；远处先“走近守卫”，抵达后仍需明确迎战。无损直接写“本战无损”，原“零损敌情精简显示”设置仍生效。
- 预计力竭时主动作改为“暂避此战 Esc”。F 保留原有危险战斗保护；Esc 和暂避按钮统一退出并恢复地图焦点。主动冒险仍可在详情中明确点击“仍要迎战 · 会力竭”，没有禁止玩家原本可作出的决定。
- 筹算、规则、成长路线和加入推演统一放入“战前详情”。展开后可选“成长对策 / 敌情规则”；最终决战另有“临战准备”。规则中不再复制一份战损预览。
- 最终决战保留唯一主入口“进入决战布阵 F”；查看准备、标记路线和加入推演不消耗资源，费用仍在真正战斗时结算。
- 窄 PC 窗口下主要动作铺满书写区，摘要和动作保持可见，只有详情独立滚动。选择规则或缩小窗口后会将实际详情带入阅读区，并显示当前查看的类别。当前目标在正常场景中保留，展开详情时在签页内提供简短目标。

复用现有纸卷框皮、金边与朱砂操作，不增加窗口或侧栏。正式入口、新版试玩更新 UI / 样式缓存版本到 v35；引擎、地图、敌人数值、有限资源和存档格式未改。

## 实际验证

`scripts/prepare_v35_fixtures.cjs` 生成真实存档：正常迎战、无损、远处守卫和最终决战来自既有合法主线行动前缀。危险铜面罗汉存档来自同一行动序列的另一走法：绕过可选治疗、保留道具，不修改生命或资源，最终停在原序列索引 734 的迎战动作之前，实际生命 79、战损 80。来源、合法绕行、预览及存档哈希见 `audits/v35-fixtures/manifest.json`。

`tests/v35-battle-focus-browser.cjs` / `audits/v35-battle-focus.json` 验证：

- PC Chrome，两套实际解锁画境，1280×720 / 629×678 / 1440×900；纸卷文字与按钮安全区、默认只显示一个主要动作、详情收起后的隐藏状态。
- 查看、筹算、成长路线、加入推演与布阵不改变战斗资源；靠近只执行合法步行，不自动开战。
- F 真正迎战只结算一次，扣血和胜利功德与引擎预览一致；危险预览下 F 不战，Esc / 暂避不扣血；在详情中主动进行危险战斗会真实力竭且不发奖励。
- 详情内的末尾操作在窄窗口可滚动抵达，滚动不会带走主要操作；普通胜利与无损状态、零损精简设置、最终决战入口及离线 `index.html` 直开均复核。

代表画面按原尺寸逐张查看。已提交 `audits/v35-material-fatal-1280-card.png` 与 `audits/v35-material-safe-1280-card.png`；完整场景、规则阅读与青绿画境截图留在本机 `audits/`。

本次为战前 UI 定向验收；合法通关序列用于产生真实检查点，没有将导入存档当作本轮重新试玩完整十八层的证明。旧基线文件字节保持不变，移动端与广泛浏览器兼容仍按项目约定后置。
