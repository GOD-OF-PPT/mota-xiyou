# v38 经卷展开定位修复

2026-10-26。用户截图中，“此层经卷”展开后，地图规划和归位按钮被挤到纸卷中间高度，入口与内容脱离。

## 根因与修正

`css/image-ui.css` 的共用框皮规则把经卷面板设为 `position:relative`，覆盖原有绝对定位。长内容进入 flex 工具栏的正常排版，撑高整行，其他按钮随之垂直居中。这是布局样式相互覆盖，不是地图或素材坐标错误。

- 框皮只负责材质与边框；经卷的定位不再被共用框皮覆盖。
- 面板以经卷按钮为参照，始终在其下方 8px 展开，开合不会改变工具栏高度或其他按钮的位置。宽窗口左对齐，760px 以下的 PC 窗口右对齐。
- 保留纸卷边框及安全留白，宽度最多 420px，整体限制在视口内。长内容仅在卷内滚动，目标按钮允许换行，末尾手记入口仍可到达。
- 展开箭头反转；Esc 优先收卷并把键盘焦点还给经卷入口，不清除已选地图目标。同层定位及进入手记继续自动收卷。
- 正式入口、新版试玩的相关缓存版本更新为 v38。冻结基线未改。
