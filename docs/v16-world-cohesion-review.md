# v16 地图、人物与物件的场景衔接

2026-10-23。用户反例为 `audits/v16-user-grounding.png`：人物、残钟台、莲灯与楼梯像独立模型摆在平面贴图上。v14 的原生像素与高清物件保留；清晰度并不能代替落地关系。

## 复现与根因

- 物件只有通用柔和椭圆阴影，缺少地面嵌合、紧贴底座的遮蔽和统一方向的投影。
- 悟空使用统一源锚点，但实际靴底在各动作帧里的横向位置不同。泛用阴影不能精确贴合落脚；角色还额外提亮 8% 并加描边，进一步放大了贴片感。
- 下行楼梯使用一张独立、凸起的楼梯模型；地面没有开口、内壁与明暗递进。
- 常驻操作提示条正压住第二层楼梯入口，进一步打断地面与建筑的连接。

修复前先用从新游戏重放的合法路线生成三个固定检查点，保存相同 PC 视口的前图。庭院检查点额外合法向左、向下各走一步，让人物、残钟台、莲灯与楼梯同时入镜，没有修改坐标或注入资源。

## 改动

1. **石基沿用庭院材质。** 莲灯、契台、校准塔、宝匣与固定机关增加嵌入铺地的基础。直接采样当前位置的原始地砖纹理，使用薄石缝、磨损边缘和接触暗部；基础限制在自己的真实可走格内，不增加道路或阻挡。
2. **统一落脚和光向。** 实体以左上来光投出真实轮廓阴影，接触部位再补紧阴影；飞行生物保留悬空差异。靴底接触位置来自原图逐帧测量，阴影与当前动作、当前绘制落点同步。取消额外亮边与提亮，材质角色使用轻微统一色调。
3. **楼梯嵌入地面。** 玄金画境的下楼梯改为切入地坪的楼梯井，绘制石质切边、内壁、七级台阶和越向深处越暗的光照。场景几何直接在最终 DPR 画布绘制，命中、深度排序和楼梯逻辑继续使用原实体。
4. **灯光落到石面。** 莲灯等光源的地面反射沿地面压扁，不再把空中圆形光晕当作落地依据。
5. **操作提示移到 PC 边缘。** 左下角显示操作模式，给楼梯入口让位；当前目标仍保留。移动、点击、E 交互、取舍与存档规则均不变。

第一版基础过大、边线过重，看起来又像加了一块独立方板。原尺寸复看后收窄到实体自己的格子，减薄边线，并把缩小的整张纹理换成原位置连续纹理。随后补上轮廓投影，并在实机发现、移走挡住楼梯的提示条。前后图保留在 `audits/v16-before-*` 与 `audits/v16-after-*`。
