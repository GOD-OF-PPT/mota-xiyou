# v44 本地 MP3 背景音乐

2026-10-27。接入用户提供的四个原始 MP3，按首页、游戏中、胜利页三个场景播放。

## 行为

- 首页每次进入时随机选择 `title-01.mp3` / `title-02.mp3`，播完自动换另一首；普通界面刷新不重选、不重播。
- 游戏中循环 `exploration.mp3`，胜利页两个结局均循环 `victory.mp3`。展开胜利回忆不会重启音乐；回看塔景、重开、继续和返回标题按实际界面切歌。
- 场景交接约 700ms 淡入淡出，最多保留一条当前曲目和一条正在淡出的曲目，完成后移除旧播放器。首页 / 胜利音量 38%，游戏中 28%。
- 删除旧背景合成旋律的定时器，动作与机关音效继续独立使用 Web Audio。跳过神通或剧情不切断背景音乐。
- 未明确设置过音乐偏好时默认开启，已保存的关闭选择继续生效。首页增加与画风一致的音乐按钮，支持鼠标、Enter 和 Space；游戏内“声音与演出”保留独立的音乐 / 音效开关。
- 首次真实点击或键盘操作解锁播放；不绕过浏览器自动播放限制。切到后台时暂停，回来续播；载入失败不阻塞游戏，首页允许明确重试。首页调整音乐不创建或覆盖战役存档。
- 快速暂停 / 恢复复验发现旧 `play()` 请求回调可能覆盖后续恢复，已为每次播放分配请求代号，暂停时使旧请求失效；陈旧回调不再清除新请求的状态或打断新播放。

## 资源与入口

文件位于 `assets/audio/bgm/`，相对地址支持局域网 HTTP 与离线 `file://`。四首为 44.1kHz 双声道 MP3，约 17.9 MB（十进制），未转码或改写。

`index.html`、`playtest-v23-new.html` 的音频、UI 和相关布局缓存号更新为 44；冻结对照页不改动。引擎、地图、有限资源、十八层与双画境规则不变。

## 验收记录

- `tests/v44-audio-browser.cjs` / `audits/v44-audio.json`：局域网 IP 入口真实音频解码与播放时间推进、首页自然播完换曲、两种随机选曲分支、探索 / 胜利自然循环、独立音效开关、音乐关闭偏好刷新保留、键盘解锁、合法终局检查点确认与返回、离线直开和新版隔离试玩。
- 测试循环采用浏览器真实 16 倍播放直至曲末，没有伪造 `ended` 事件。使用既有合法检查点导入后确认结局，仅证明音乐接线，不据此重述完整十八层通关验收。
- `tests/v44-audio-controls.cjs` / `audits/v44-audio-controls.json`：1280×720 按钮可见、首页开关不创建战役存档、快速返回 / 继续与播放 Promise 中断恢复、缺失音频不影响游戏继续。
- 暂停 / 恢复已验证播放器生命周期。无头浏览器标签切换仍报告 visible，未将它描述成真实后台标签行为验收。
- 1440×900 首页与胜利代表截图、1280×720 首页逐张原尺寸检查。内嵌浏览器实际打开局域网 v44 页并点击奏乐，读取到 `title-02.mp3` 在 21 秒处持续播放，未暂停、无媒体错误；截图 `audits/v44-live-title.png`。

本轮验证解码、播放、循环、切换与界面操作，不将自动化结果当作人工听感、循环接缝听辨或最终混音验收。最终状态与文件哈希见 `audits/v44-final.json`。
