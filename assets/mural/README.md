## 技术管线

`python scripts/prepare_mural_assets.py`只做透明alpha清理、孤立噪点清理、共享尺度/脚点注册、最近邻缩放与打包，不画替代美术。源PNG保留，输出可重建；运行所需文件已经存在，游玩不执行脚本。主角全16帧共享缩放，攻击帧不单独等宽缩小；FX保留统一格中心，避免光环逐帧漂移。

`TowerAssets.preload(onProgress)`加载9个本地URL，回调和resolve给出 `{loaded,total,failed}`；`get(id)`返回图片及裁帧元数据；`draw`/`drawTile`只读图集、缺资源返回false。正常路径使用真实PNG，失败会由界面说明并允许基础图形继续。直接file打开亦可用，不依赖fetch、远程字体或后端。

渲染逻辑格仍为16单位，原生图层按3倍绘制为48px/格。21格场景buffer1008²，13格近观裁624²，整图仅用于规划缩放。像素采样关闭平滑；角色按脚点排序；地标裁透明留白后限制于不可通行占地，不能盖住路、敌人或物品。地表按世界坐标连续取样，机关/水位/任务/觉醒和资源就绪变化使地形缓存失效。

## 表现与权威边界

引擎先完成扣血、扣钥匙、驻守和开路，再发出带来源、目标、材质、阶段、费用的事件。金箍延伸、青蝉往返、毫毛落阵、反向召回、材质开门、拾取与局部受击均只呈现事件。化蝉不伪造真身位移。新动作收束旧效果；跳过、简洁和系统减弱动态不改变结算。

强效果用于印觉醒/三相/无骨；单枚外舍利仅650ms轻反馈。减弱模式使用静态确认，关闭位移粒子、斩击、浮字旅行、背景动态和震动；震动默认关闭。水/断口/云以可辨材质和流向TA表现，不能把墙纹当弱水。

## 证据

PNG真载入、六章/四向/FX/减弱动态、视口与失败注入的证据位于 `tests/v5-*`、`audits/v5-*`。最终源图/实图同视口和聚焦区域对照在项目根 `design-qa.md`，将清楚区分源稿构图与实际关卡几何的有意差异。没有使用概念稿替代战斗逻辑，也不以资源数量声称真人美术或趣味已获验证。
