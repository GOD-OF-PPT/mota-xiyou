# 背景音乐文件约定

将用户生成的四个 MP3 原始文件放在本目录，不要只修改其他音频格式的扩展名。

|文件名|用途|
|---|---|
|`title-01.mp3`|首页背景音乐一|
|`title-02.mp3`|首页背景音乐二|
|`exploration.mp3`|游戏中背景音乐|
|`victory.mp3`|胜利页背景音乐，两个结局共用|

已接入 `js/audio.js` 与 `js/ui.js`：每次进入首页随机选一首，播放结束切换另一首；游戏中与胜利页各自循环。切换场景使用约 700ms 淡入淡出，不叠加原合成背景配乐，保留独立动作音效与声音开关。游戏中音量为 28%，首页与胜利页为 38%。

音频使用本地相对路径，保留直接打开 index.html 与离线运行。浏览器播放限制遵循首次用户交互解锁。

未曾明确设置音乐偏好时默认开启；已有关闭偏好继续保留。首页“点此奏乐 / 开启音乐 / 音乐已开启”按钮支持解锁与开关，游戏内可在“声音与演出”独立调节背景音乐和动作音效。首页调整开关不创建或覆盖战役存档。

隐藏页面时暂停音频，返回后从当前曲目位置继续；跳过剧情只终止短音效，不停止背景音乐。音频载入失败时允许游戏继续，首页可主动重试。

四首原始 MP3 均为 44.1 kHz 双声道，未转码或改写。`exploration.mp3` 约 130 秒，`title-01.mp3` 约 145 秒，`title-02.mp3` 约 166 秒，`victory.mp3` 约 116 秒。
