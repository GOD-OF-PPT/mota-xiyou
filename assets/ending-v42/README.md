# Static victory artwork

Generated with the built-in `image_gen` tool for the two completed campaign endings. Full final prompts, dimensions and byte sizes are in `prompts.json`.

- `release.png`: 1672×941, Sun Wukong leaving the black-gold temple into dawn.
- `keep.png`: 1672×941, Sun Wukong guarding a warm eternal lamp at the temple threshold.

The selected PNG outputs are copied intact into the workspace. No UI text or buttons are baked into them. `css/victory.css` places real game text and controls over the quiet left side. These narrative illustrations are shared by the material and mural map styles; both map asset families remain available under their existing unlock rules.
