# 玄金神怪 · 三维古寺

本套以此前三维方案 `reference-selected.png` 为造型、材质和光照参考：湿石、炭黑寺构、古金雕饰、朱红披帛、玉色灯火。它与青绿壁画是两套独立的运行资源，游戏内可即时切换；规则、关卡和存档不随画境改变。

这是**三维材质风格的预渲染二维图集**，不是实时三维模型或 PBR 网格。没有用整张设计稿代替游戏地图。远景 `ui_backdrop.png` 没有角色、道具、格点或界面，只在开始场景及真实地图外侧提供空间层次。

资源由内置 ImageGen 生成。原始版本、两位剧情人物的修正版均保留在 `source/`；提示规格见 [prompts.json](prompts.json)。`scripts/prepare_material_assets.py` 只承担技术裁片、透明噪点清理、脚点注册、共享缩放、抗锯齿重采样与图集打包，不绘制替代角色。

`manifest.json` 与 `js/material-assets.js` 来自同一生成步骤。基础145个寻址ID全部兼容壁画套，另有6个NPC头像ID，总151个ID包含别名；不能理解为151张独立插画。v7的9张运行PNG约12.66MB，无外部字体、CDN或运行时构建依赖。

材质套保留柔和alpha和平滑采样；壁画套使用最近邻采样。悟空16帧采用相同缩放，按脚点左右可用范围共同约束，长棒和长翎不再因对齐而裁断。独立肖像不受全身帧留白影响。世界角色的显示倍率由渲染器统一处理，碰撞仍为真实格点。

v7高清帧从 `source/` 直接重建，未把既有小图放大冒充新细节。`logicalScale`使帧尺寸、anchor和bounds的物理提升不改变世界体量；`frameBounds`给出每方向每动作的真实内容，避免长棒union造成巨大空点击范围。材质动态角色/效果直接在最终DPR层绘制，地表缓存倍率由 `sourceW / tileCells / 16` 得出（当前为6）。这解决的是源图细节损失与中间重采样，不虚称任意DPR均达到源像素1:1。

切换由 `TowerStyle.set('material'|'mural')` 执行，按需载入本地图片，完成后原子替换资源组。失败保留当前画境并显示真实错误；切换本身不访问引擎或存档。直接双击 `index.html` 仍可运行。
